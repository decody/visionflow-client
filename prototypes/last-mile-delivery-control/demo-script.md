# Last-mile Delivery Control 시연 스크립트

## 시작 상태

- 기본 함대: 고정 seed 기반 라이더 40대 (운영바 `함대` 선택기로 500/1k/2k/5k 전환)
- 초기 카메라: 강남 전체 권역이 보이는 Overview LOD
- 기본 세션 역할: `감독(supervisor)` — 운영바 `역할` 선택기로 조회·배차로 낮춰 연동 경계를 시연
- 데이터: 실제 배송 플랫폼이 아닌 로컬 합성 시뮬레이션
- 지도 배경: OpenStreetMap 공개 강남 도로망(오프라인 벡터, 외부 타일·API 키 없음)
- 화면 표기: `Prototype #03 · 합성 데이터 · OSM 공개 도로망`

## 자동 데모 플로우

시나리오 바의 `자동 데모`를 켜면 약 60초 동안 아래 순서가 재생된다(고정 seed로 재현).

| 시간 | 단계 | 확인 포인트 |
| ---: | --- | --- |
| 0초 | 정상 운행 | 라이더 이동, 권역 KPI, 주문 파이프라인 |
| 8초 | 수요 서지 | 미배차 대기열 급증, backpressure |
| 16초 | 교통 정체 | 구간 순항 속도 저하, ETA 증가 |
| 24초 | 도로 통제·우회 | 테헤란로 통제 구역 강조, 라이더 경로 우회(재탐색) |
| 32초 | 정체 해제 | 속도·ETA 회복 |
| 40초 | 통제 해제 | 우회 경로가 최단 경로로 복귀 |
| 44초 | 라이더 저배터리 | 배터리 위험 알람, 허브 복귀·충전 전환 |
| 52초 | 서지 해소 | 대기열 정상화 |
| 58초 | 정상 복귀 | LIVE 운행 유지 |

> 신호 교차로는 항상 켜져 있다 — 지도 상세 LOD에서 주요 사거리의 녹/적 신호등이 주기적으로 바뀌고, 라이더가 적신호 정지선에서 **감속→정차→재가속**(가·감속 프로파일)한다. 인스펙터 `속도`가 이 램프업/다운을 실시간으로 보여준다.

## 연동 경계(역할·감사) 시연

1. `역할`을 **조회(viewer)** 로 낮춘 뒤 배차 규칙·재배차·시나리오 주입을 시도 → 모두 거부되고 **감사 타임라인**에 빨간 점(거부·사유)으로 남는다.
2. `역할`을 **배차(dispatcher)** 로 올리면 운영 조치(재배차·라이더 연락·특급 승격)는 승인되지만 시나리오 주입은 여전히 거부된다.
3. `역할`을 **감독(supervisor)** 으로 올리면 교통 정체·수요 서지·도로 통제·저배터리 주입까지 승인된다.
4. 운영 조치 바의 승인/거부 메시지와 감사 타임라인이 매 명령마다 갱신되는지 확인한다.

## 수동 시연 포인트

1. 권역 밴드를 클릭해 지도·라이더 목록·주문 파이프라인이 같은 권역으로 좁혀지는지 확인한다.
2. 라이더를 클릭해 상세(상태·주문·ETA·배터리·heading·좌표)와 배송 추적선·목적지를 확인한다.
3. 알람 행을 클릭해 영향 라이더로 포커스를 이동하고, `확인`으로 ack 처리한다.
4. 이력 재생 바에서 최근 60초를 1·2·4× 재생한 뒤 `LIVE`로 복귀한다.
5. `진단`을 켜고 FPS·msg/s·upd/s·coalesced%·resync·렌더(보이는/전체)·JS heap을 확인한다.
6. `함대`를 5k로 올려 WebGL 포인트 렌더와 뷰포트 컬링(`렌더(보이는/전체)`)이 동작하는지 확인한다.

## 방식 B(ws 소켓) 시연

- `pnpm ws:server`로 로컬 ws 서버(:3014)를 띄우고 `http://localhost:3013/?src=ws`로 접속한다.
- 서버를 잠시 껐다 켜면 재연결(backoff)·heartbeat·스냅샷 재동기가 동작한다.

## 캡처 권장 장면

- 강남 전체 + 권역 KPI + LIVE 상태
- 교통 정체·수요 서지 시 ETA·대기열 변화
- 도로 통제 활성 시 통제 구역 강조 + 라이더 우회 경로(선택 라이더 추적선)
- 상세 LOD에서 신호등 녹/적 전환과 라이더 정지선 대기
- 조회 역할에서 거부된 명령이 감사 타임라인에 남는 장면
- 이력 재생 화면과 LIVE 복귀 상태
- 5,000대 부하에서 개발 진단 패널(렌더 보이는/전체)
