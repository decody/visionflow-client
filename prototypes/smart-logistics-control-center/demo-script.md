# Smart Logistics Control Center Demo Script

이 문서는 고정 seed로 실행되는 단계 9 시연 순서다. 화면 우측 상단의 합성 데이터 고지를 유지하고, 시연 중에는 실제 운송망이나 실시간 운송사 피드로 오해할 수 있는 설명을 하지 않는다.

## 실행

```bash
pnpm dev
```

브라우저에서 `http://localhost:3015`를 연다. 방식 B를 확인할 때는 별도 터미널에서 `pnpm ws:server`를 실행한 뒤 `http://localhost:3015/?src=ws`로 접속한다.

## 90초 시연 순서

1. 초기 화면에서 3D 글로브, 국가 경계, 허브 노드, 대권항로 arc, LIVE 배지를 확인한다.
2. 좌측 역할을 `viewer`로 바꾸고 화물 목록과 모드·상태·Expedite 필터가 동작하는지 확인한다.
3. 화물을 선택해 Drawer를 열고 leg 타임라인, ETA, SLA, 현재 상태를 확인한다.
4. 권역 칩을 눌러 MapView로 전환하고, `글로브` 버튼으로 복귀한다. 전환 중 viewState 보간과 권역 필터 동기화를 확인한다.
5. 역할을 `dispatcher`로 바꿔 알람을 ack하고, 화물 Drawer에서 Expedite 또는 재경로를 선택한다. 확인 상자에서 취소와 승인을 각각 한 번씩 보여준다.
6. 역할을 `supervisor`로 바꾼 뒤 `항만 혼잡`을 켠다. 허브 dwell 증가, SLA 위험, DWELL/CAPACITY 알람을 확인한다.
7. `운하 폐쇄`를 켠다. 레인 차단, 영향 화물 재경로, CLOSURE 알람을 확인한다.
8. `자동 데모`를 켜고 정상 운송 → 혼잡 → 폐쇄 → 기상 → 통관 → 서지 → 복구 흐름을 관찰한다.
9. 링버퍼에 프레임이 쌓이면 `이력 재생`에서 1×·2×·4× 속도, seek, `LIVE 복귀`를 확인한다.
10. 진단 패널을 열어 FPS, msg/s, upd/s, coalesced, resync, 렌더 대상을 보여준다.

## 완료 판정

- 합성 데이터·공개 경계 데이터·실제 운송망 아님 배지가 항상 보인다.
- 고정 seed로 새로고침해도 첫 상태와 자동 데모 순서가 동일하다.
- 1,000 운송수단·10,000 화물 코어 벤치가 10Hz 및 p95 200ms 기준을 통과한다.
- 5,000 운송수단·50,000 화물은 스트레스 결과로 별도 기록하며, 브라우저 렌더 성능은 진단 패널에서 확인한다.
