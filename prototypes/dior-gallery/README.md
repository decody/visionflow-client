# Dior Gallery Prototype

VisionFlow Web3D portfolio prototype 01. This package is isolated from `@visionflow/web` and runs on port 3010.

```bash
pnpm --filter @visionflow/dior-gallery dev
pnpm --filter @visionflow/dior-gallery build
```

Source photographs remain in `E:/PROJECT/dior-gallery/raw`. Web assets in this prototype are copies of the 20 selected photographs.
