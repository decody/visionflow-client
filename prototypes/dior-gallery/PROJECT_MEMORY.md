# Dior Gallery 프로젝트 메모리

업데이트: 2026-08-14

## 프로젝트 위치와 실행

- 워크스페이스: `E:/PROJECT/visionflow/visionflow-client`
- 프로토타입: `prototypes/dior-gallery`
- 개발 서버: `http://localhost:3010`
- 기술 스택: Next.js, React, TypeScript, Three.js, React Three Fiber, Zustand

## 전체 콘셉트

스크롤을 따라 `ARCHIVE → ATELIER → ROUGE → REVERIE` 네 장면을 이동하는 Dior Web3D 포트폴리오 프로토타입이다. 전역 파티클은 보라색, 청색, 노란색, 붉은색 계열로 발광하며 움직인다. 각 장면의 제목과 설명은 랜덤 문자에서 원문으로 복원되는 Scramble 애니메이션을 사용한다.

## 장면별 현재 상태

### Archive

- 상단이 둥글고 옆면과 바닥이 평평한 터널형 3D 공간이다.
- 아카이브 이미지는 얇은 액자에 넣어 터널 벽면 각도에 맞춰 배치했다.
- 인트로에서 Archive로 진입할 때 휠 이동으로 공간이 뒤에서 앞으로 다가온다.
- `DRIFT INTO THE MARVELOUS` 전환 문구를 사용한다.

### Atelier

- 밝은 아이보리 작업실 콘셉트다.
- 네 개의 이미지 액자를 격자 기반 비대칭 구성으로 배치했다.
- 액자는 서로 겹치지 않으며 벽면에 가깝게 붙어 있다.
- 오른쪽 바닥에는 재단 테이블, 토르소, 가위, 패턴 종이와 원단 소품이 있다.
- 이미지 Hover와 클릭 모달은 제거했다.
- Archive → Atelier 전환 글로우는 짧고 잔광이 남지 않도록 조정했다.

### Rouge

- 기존 거울 패널 콘셉트는 폐기했다.
- 붉은 삼각 패싯으로 구성된 크리스탈 벽면과 중앙의 깊게 파인 직사각형 니치를 사용한다.
- 벽면은 Clearcoat, 높은 Metalness, 낮은 Roughness와 이동 광원으로 반짝임을 표현한다.
- 실제 평면 반사는 모바일 성능 비용 때문에 사용하지 않는다.
- 중앙 니치에는 파란색 핸드백 이미지 `IMG_6079.jpg`를 임시 사용한다.
- 핸드백 이미지는 블러, 컬러 오버레이, 밝기 보정 없이 원본 그대로 표시한다.
- 핸드백은 Rouge 구조물과 동시에 생성되며 깊이 검사를 유지해 Atelier 벽을 뚫고 보이지 않는다.
- Rouge에서는 커서 오라를 숨기지만 벽면의 광원 반응은 유지한다.
- 광택 있는 Rouge 전용 바닥이 있으며 가로 폭은 크리스탈 벽과 동일한 `15`다.
- 벽과 바닥 접점에는 얇은 반사 라인이 있다.

### Reverie

- 중앙에 드레스 한 벌만 집중 배치한다.
- 드레스는 기존보다 25% 크게 표시한다.
- 마우스의 가로 이동에 반응해 Y축 기준 최대 약 40도로 회전한다.
- Hover와 클릭 모달은 제거했다.
- 여러 벌의 드레스 배경 이미지는 임시로 숨겼다.
- 별도 무대 원형 바닥과 중간 배경 레이어를 제거했다.
- 금빛 70%, 은빛 30% 크리스탈 파티클이 드레스 중심으로 모였다가 퍼진다.
- Reverie 파티클은 마우스에 반응하지 않고 일정한 주기로 반복한다.

## UI와 인터랙션

- 왼쪽 중앙에 장면 제목과 3~4줄 영문 설명을 표시한다.
- 제목은 굵은 대형 타이포그래피이며 랜덤 문자 복원 애니메이션을 사용한다.
- Archive의 텍스트 애니메이션은 인트로 버튼 클릭과 배경 이미지 등장 이후 시작한다.
- 오른쪽 아래 장면 번호는 작은 둥근 사각형 버튼이다.
- 활성 버튼 배경은 흰색 40% 투명도를 사용한다.
- 인트로의 Scroll 안내는 중앙에서 시작해 휠 이동 후 하단으로 이동한다.

## 구현 주의사항

- `Artwork`는 이미지별 밝기, 깊이 검사와 렌더 순서를 제어할 수 있다.
- Rouge 핸드백은 높은 렌더 순서를 사용하지만 깊이 검사는 켜져 있어야 한다.
- Rouge 핸드백에 `depthTest={false}`를 다시 적용하면 Atelier 전환 중 벽을 뚫고 먼저 보이는 문제가 재발한다.
- Rouge 핸드백에 별도 진행률 지연을 적용하지 않는다. 벽면과 동시에 보여야 한다.
- 장면 변경 후 개발 서버의 HMR로 WebGL Context가 유실되면 새로고침 후 검수한다.
- 현재 변경사항에는 기존 사용자의 여러 미커밋 작업이 포함되어 있으므로 관련 없는 파일을 되돌리지 않는다.
