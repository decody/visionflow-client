# AMHS OHT Control 시연 스크립트

## 시작 상태

- 기본 fleet: 고정 seed 기반 OHT 8대
- 초기 카메라: FAB 전체가 보이는 Overview
- 데이터: 실제 MES/AMHS가 아닌 로컬 합성 시뮬레이션
- 화면 표기: `Prototype #02 · 합성 FAB 시뮬레이션`

## 자동 데모 플로우

왼쪽 패널의 `자동 데모 시작`을 누르면 58초 동안 아래 순서가 재생된다.

| 시간 | 단계 | 확인 포인트 |
| ---: | --- | --- |
| 0초 | 정상 운행 | OHT 이동, Bay KPI, 작업 목록 |
| 3초 | Hot lot 승격 | 우선순위와 Hot lot 강조 |
| 6초 | 포트 장애 | 영향 작업, 대기 OHT, 설비 포커스 |
| 14초 | 포트 복구 | 대기 해소와 운행 재개 |
| 16초 | 레일 폐쇄 | 폐쇄 구간과 자동 우회 |
| 24초 | 레일 개통 | 정상 경로 복귀 |
| 26초 | 저장소 포화 | 용량 0, 하역 대기, JAM |
| 36초 | 공간 확보 | 하역 재개 |
| 38초 | 통신 단절 | 화면 정지와 재연결 상태 |
| 44초 | 통신 복구 | 스냅샷 재동기 |
| 46초 | 저배터리·충전 | 배터리 알람과 충전 복귀 |
| 54초 | 충전 완료 | 정상 상태 회복 |
| 58초 | 데모 완료 | LIVE 운행 유지 |

## 수동 시연 포인트

1. Bay KPI 카드를 클릭해 지도·작업 목록이 같은 Bay로 좁혀지는지 확인한다.
2. 작업 목록에서 Job을 클릭해 OHT 상세·경로 오버레이를 확인한다.
3. 알람 행을 클릭해 영향 설비·포트·세그먼트로 이동한다.
4. `⏱ 이력 재생`에서 최근 60초를 재생한 뒤 `● LIVE`로 복귀한다.
5. `개발 진단`에서 FPS, 렌더 p95, culling 대상, 메시지 지연을 확인한다.

## 캡처 권장 장면

- 전체 FAB + Bay KPI + LIVE 상태
- 포트 장애 영향 범위와 OHT 상세
- 레일 폐쇄·우회 및 JAM 알람
- 이력 재생 화면과 LIVE 복귀 상태
- 5,000대 부하에서 개발 진단 패널
